# Prosey Index — Spec

## 1. Overview

The index is a static `index.html` at the data dir root (e.g.
`~/.local/share/prosey/index.html`) listing every document — summaries and
transcriptions — stored in the data dir. It uses the same design language as
content pages (Pico classless, Plus Jakarta Sans, logo header, theme toggle).

## 2. Discovery

Documents are discovered by scanning the data dir for folders matching the
cache-key pattern (`<videoId>_<hash>`). A folder is a document when it contains
`summary.md` and/or `transcript.md`. Metadata (title, channel, channelId,
channelDescription, duration) comes from `info.json`; a missing or unparseable
`info.json` falls back to the folder name as title.

Each document row shows:

- Title — links to the summary.html if present, else transcript.html, else the
  markdown file
- Channel — watch duration · read time (200 words/min, from the md word count)
- Creation date — mtime of the newest content file (`summary.md` /
  `transcript.md`)
- `Summary` and/or `Transcript` badges — link to the corresponding html page
  (markdown as fallback)

Rows are sorted newest first by content-file mtime.

## 3. Rendering on rebuild

During a rebuild, any document whose content lacks an html page — or whose
html page predates the current template (no `<!-- generated by
prosey:content-v2 -->` marker) — is rendered from its markdown and written to
`<key>/summary.html` / `<key>/transcript.html`. Pages with the marker are left
untouched, so rebuilds are idempotent and content mtimes stay stable.

## 4. Rebuild triggers

- End of every `summarize` run (fresh or cache hit)
- End of every markdown/html `transcribe` run (fresh or cache hit)
- Explicitly via the `prosey index` command, which also opens the index in the
  browser
- `prosey render` — regenerates every content HTML page from cached markdown
  (ignoring the template marker, no network or AI processing) and rewrites the
  index

## 5. Navigation

Content pages (`summary.html`, `transcript.html`) wrap the header logo in a
link to `../index.html` (relative, works over `file://`). On the index page
itself the logo is not a link.
